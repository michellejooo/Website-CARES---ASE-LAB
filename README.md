# CARES

CARES is a web-based facility damage reporting system for the campus environment.
The system helps students, employees, and lecturers report damaged campus facilities. It also helps administrators manage reports, update report status, and monitor the handling process.

## Project Overview

CARES provides a simple and organized way to report and track campus facility problems.
The system has two main roles:
- User: Creates and tracks facility damage reports.
- Admin: Manages incoming reports and updates their status.
The project is developed as part of the Advanced Software Engineering Laboratory internship at Telkom University.

## Main Features

### User

- Register an account
- Login and logout
- Reset password
- Create a facility damage report
- Select a problem category
- Select a building with autocomplete
- Enter floor and room information
- Add a damage description
- Upload damage photos
- Submit a report anonymously
- View report history
- View report details and status
- Receive report status notifications
- Manage notification preferences

### Admin

- Login
- View all incoming reports
- Filter reports by status
- View report details
- Update report status
- Upload repair proof when a report is completed
- Add a reason when a report is rejected
- Logout

## Report Status

Reports can have the following statuses:
- Menunggu
- Diproses
- Selesai
- Ditolak

## System Scope

CARES focuses on recording and tracking campus facility damage reports.
The system does not include:
- Interactive maps
- GPS location tracking
- Live chat between users and technicians
